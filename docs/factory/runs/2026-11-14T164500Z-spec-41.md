Interactive factory-spec for FQ-41 (voice detection's ONNX Runtime loaded from a CDN pinned
to an older version), at the owner's request after triage marked it ready-to-spec with a
suggested high priority.

Gates:
1. Product: approved, then **re-approved after an evidence correction**. The first draft
   called the runtime failures intermittent ("2 of about 12"). Measurement showed the test
   sandbox's proxy refuses cdn.jsdelivr.net, so every attempt failed, and hearing had only
   been attempted in some runs. The case was restated as blocked networks, the third-party
   request and the version skew. Owner decisions: include the "can't hear you" message, with
   the proposed wording.
2. Architecture: measured rather than inferred. With the autoplay flag and CDP request
   logging, the runtime requests `ort-wasm-simd-threaded.mjs` and then `.wasm` from
   `wasmPaths`, and the existing e2e suite never loads voice detection at all. factory-critic
   verdict: needs changes. Owner decisions: any not-ready state at 10 s shows the message, a
   late load recovers, and a dedicated avatar state.
3. Design and 4. Slices: **waived by the owner**, who asked for the fix and its tests in one
   interactive PR.

Outcome: implemented in PR #77 (merged 2026-11-14T19:24:18Z); see
`2026-11-14T170443Z-implement-41.md`.
