Lessons for constraint review:
- The new `prove-test.sh --precheck` rule worked as intended here: `next build` type-checks
  `tests/unit/`, so a new unit test importing a not-yet-written module breaks the build. A
  spec-only `--test-path` reverts both and the base builds; the spec then failed on
  assertions.
- Verifier subagents must not share the implementer's checkout. Run them in an isolated
  worktree, and have the implementer confirm the current branch before every push.
- Put each "neither X nor Y" check in its own (or a soft) assertion, so the proof exercises
  both halves.
